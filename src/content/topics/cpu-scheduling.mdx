## Intuition

A CPU can only run one process at a time. When multiple processes are ready, the OS must decide which one runs next. This is **CPU scheduling**. The choice dramatically affects system performance — poor scheduling means long waits, wasted CPU time, and unhappy users.

## Formal Concept

### Key Metrics

- **Arrival Time (AT):** When a process enters the ready queue
- **Burst Time (BT):** How long the process needs the CPU
- **Completion Time (CT):** When the process finishes
- **Turnaround Time (TAT):** CT - AT (total time in system)
- **Waiting Time (WT):** TAT - BT (time spent waiting)
- **Response Time:** First CPU allocation - AT

### Algorithms

**1. FCFS (First Come First Served)**
- Non-preemptive: once a process gets the CPU, it runs to completion
- Simple but causes **convoy effect** — short processes wait behind long ones
- Avg waiting time can be very poor

**2. SJF (Shortest Job First)**
- Non-preemptive: pick the process with smallest burst time
- Optimal for minimizing average waiting time
- Problem: **starvation** — long processes may never run

**3. SRTF (Shortest Remaining Time First)**
- Preemptive version of SJF
- If a new process arrives with shorter remaining time, preempt current
- Better avg waiting time than SJF but more context switches

**4. Priority Scheduling**
- Each process has a priority number (lower = higher priority)
- Can be preemptive or non-preemptive
- Starvation solved by **aging** — gradually increase priority of waiting processes

**5. Round Robin (RR)**
- Each process gets a fixed **time quantum**
- If not finished, moved to back of ready queue
- Fair but performance depends on quantum size
- Too small = excessive context switches; too large = degenerates to FCFS

## Common Mistakes

1. **Confusing SJF and SRTF** — SJF is non-preemptive. SRTF can preempt. SRTF always has equal or better avg waiting time.

2. **Forgetting that FCFS is non-preemptive** — Once a process starts, it runs to completion regardless of what arrives.

3. **Choosing too small a quantum for RR** — If quantum = 1 and burst times are large, context switch overhead dominates.

4. **Not accounting for arrival time** — SJF picks the shortest process among those that have ARRIVED, not all processes.

5. **Ignoring the convoy effect** — In FCFS, one long process behind a short one causes the short one to wait unnecessarily.
